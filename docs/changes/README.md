# Completed changes

This directory is the chronological ledger of completed implementation blocks.

Each record describes what actually changed, why it changed, the files and invariants affected, the verification performed, and any follow-up left open. A record is written when a block closes. It does not replace the preimplementation plan in `docs/CHANGE_SPEC.md` or a durable architectural decision in `docs/decisions/`.

Use the filename `YYYY-MM-DD-short-change-name.md`.

`docs/BLOCK_RECAPS.md` is the historical archive for work completed before this framework was adopted. Do not duplicate new records there.
