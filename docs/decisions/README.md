# Durable decisions

This directory contains accepted architectural and product decisions that future changes must preserve until a recorded revisit trigger is met.

Each decision states its status, context, decision, reasons, consequences, and revisit triggers. Use the filename `NNN-short-decision-name.md` and never rewrite history silently. Supersede an old decision with a new record that links back to it.

`docs/DECISIONS.md` is the historical archive through 2026-07-18. New decisions live only here.
